Features

Everything you need to build UI fast

No setup, no file system, no friction. Just describe what you want and watch it appear.

⚡

Live Preview

Components render in a sandboxed iframe the moment Gemini generates the code. See changes as they stream in.

💬

Chat-driven Iteration

Refine your component through conversation. Ask for color changes, new props, animations — anything.

🗂️

Virtual File System

All files live in memory. Gemini creates and edits files using str_replace_editor just like a real IDE.

🎨

Every component is styled with Tailwind. Full class support, responsive design, and dark mode out of the box.

📁

Browse and edit generated files in a full VS Code-powered editor with syntax highlighting.

🔐

Auth + Project Saving

Sign up to save your projects to a database. Anonymous users get localStorage persistence automatically.

How it works

From prompt to preview in 3 steps

1

Describe your component

Type a natural language prompt like "a pricing card with a highlighted plan" or "an animated login form".

2

Gemini writes the code

Google Gemini 2.5 Flash streams JSX + Tailwind code, creating files in the virtual file system using AI tool calls (str_replace_editor).

3

Preview renders instantly

Babel transforms the JSX on the client, builds an import map, and renders your component live in a sandboxed iframe — no build step needed.
